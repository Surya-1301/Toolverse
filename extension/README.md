# Toolverse Video & Media Downloader (Chrome Extension)

A Chrome & Edge browser extension (Manifest V3) for downloading high-definition video and audio from web platforms and managing YouTube HD downloads via Toolverse.

---

## 🚀 How to Test in Chrome Right Now (Developer Mode)

1. Open Google Chrome.
2. Navigate to `chrome://extensions/` in the address bar.
3. Toggle on **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the `Toolverse/extension` folder.
6. The extension is now installed! Pin it to your toolbar.

---

## 🌟 Features

* **Auto Video Detection:** Detects YouTube and Instagram Reel links on your active tab automatically.
* **In-Page Action Button:** Injects a clean `⚡ Download HD` button under videos on `youtube.com`.
* **One-Click Download:** Downloads MP4 (1080p, 720p, 360p) and MP3 directly to your browser's download folder.
* **Manifest V3 Compliant:** Built using the latest Chrome Extension security standards.

---

## 📦 How to Publish on the Google Chrome Web Store

1. **Zip the extension folder:**
   Compress all files inside `Toolverse/extension` (ensure `manifest.json` is at the root of the `.zip`).
2. Go to the [Chrome Developer Dashboard](https://chrome.google.com/webstore/devconsole).
3. Click **New Item** and upload your `.zip` file.
4. Fill in the store listing:
   * **Title:** `Toolverse Video & Media Downloader`
   * **Category:** `Photos & Media` or `Productivity`
   * **Description:** Emphasize supported media platforms (Instagram, generic web videos, media tools) and Toolverse companion functionality.
5. Submit for review!
